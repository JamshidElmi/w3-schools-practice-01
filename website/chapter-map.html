How to handle comparison chapters

Icon provider chapters use Ionicons as requested: compare the loading script, icon name and CSS font-size/colour with the provider in the chapter. No Font Awesome, Bootstrap or Google icon package is installed.

Framework/template chapters: compare a premade framework class with the hand-written float grid in lab-layout.html L34. Use this completed site as the template, then make a new page manually. XHTML is a syntax comparison; deprecated browser plug-ins are replaced with supported object/embed media.

Optimization: inspect lazy loading, dimensions, system font fallback and the Network panel. Shared CSS extraction and minification are intentionally postponed to keep the source easy to teach.
